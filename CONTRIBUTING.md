# Contributing to Riottosa

Thank you for your interest in contributing to Riottosa.

Riottosa is an open-source variable display typeface made for collective voices and common causes. Contributions, feedback, bug reports, and suggestions that can help improve the project are welcome.

## How you can contribute

You can contribute to Riottosa in different ways, including:

- reporting problems with glyphs, spacing, kerning, or interpolation;
- reporting technical issues with the font files;
- suggesting improvements or additions to the character set;
- improving documentation;
- reporting issues or proposing improvements to the Riottosa website and digital specimen;
- testing the typeface and sharing useful feedback.

If you are unsure whether your idea fits the project, feel free to open an issue first.

## Reporting an issue

Before opening a new issue, please check whether a similar issue has already been reported.

When reporting a problem with the typeface, please include as much useful information as possible, such as:

- the glyphs or character combinations involved;
- the font style, weight, and width where the issue occurs;
- the application and operating system you are using;
- screenshots or examples, when useful;
- a short description of the expected and actual result.

Clear examples make issues much easier to understand and address.

## Pull requests

Pull requests are welcome.

For substantial changes, especially those affecting the design of the typeface or its character set, opening an issue first is recommended so the proposal can be discussed before significant work is undertaken.

When submitting a pull request:

1. Fork the repository and create a dedicated branch for your changes.
2. Keep each pull request focused on a specific issue or improvement.
3. Clearly describe what you changed and why.
4. When relevant, include visual examples or screenshots.
5. Make sure your changes do not unintentionally affect other parts of the typeface or website.

Please note that not every proposed change will necessarily be incorporated. Riottosa has a specific visual identity and design logic, and contributions will be evaluated for their consistency with the project.

## Licensing

Before contributing, please review the license included in this repository.

Any contribution should be compatible with the licensing terms that apply to the files being modified.

## Thank you

Riottosa is shared as an open-source project so that it can be used, tested, discussed, and improved collectively.

Every thoughtful contribution helps make the project better.
